# MedTrust 门户网站运行说明

## 一键启动

Windows 用户可在项目根目录的 `scripts` 文件夹中双击 `启动MedTrust.cmd`；结束时双击同一文件夹中的 `停止MedTrust.cmd`。

也可以在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_portal.ps1
```

浏览器打开 <http://127.0.0.1:8001>。

首次初始化新数据库前，必须设置环境变量 `MEDTRUST_ADMIN_PASSWORD`，值为 12–128 个字符；管理员用户名为 `admin`。密码使用带独立随机盐的 Argon2id 哈希保存，不会保存明文。患者可以在登录页自行注册，医生账号由管理员在“账户管理”中创建。

## 停止服务

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_portal.ps1 stop
```

## 角色权限

- 患者只能查看与本人账号关联的病历。
- 患者可以向已实名医生授权 30 天，也可以随时撤销；撤销后医生不能继续读取或提交病历。
- 医生填写的病历先保存为链下加密草稿。患者需要核对具体内容并明确同意上链，医生才能提交；患者拒绝时不会产生新区块。
- 医生完成姓名、执业证号、医院和科室认证后，才能为已授权患者提交病历。
- 医生可以为当前有效病历生成更正草稿，患者重新确认后形成新版本；旧区块保留并标记为已被更正。
- 管理员可以实名创建医生账号及进入联盟链运行大屏，但不能查看病历正文。

门户提交的病历正文使用 AES-GCM 加密后进入 Raft 日志。链上保存密文、匿名身份引用、版本引用和附件 SHA-256 摘要，门户在通过登录和授权校验后才返回可读病历。

附件原文件经过 AES-GCM 加密后保存在节点的 `data/<node>/attachments/` 目录，附件原文不进入区块链。患者和授权医生可以下载，校验功能会解密文件并重新计算 SHA-256，与链上摘要进行比较。

## 答辩演示顺序

1. 管理员登录“账户管理”，展示医生姓名、执业证号、医院和科室的实名核验字段，再进入管理员专属“区块链后台”展示三节点共识。
2. 患者登录“授权管理”，向张医生授权 30 天，说明授权到期或主动撤销后医生的读取、上传和附件访问都会立即失效。
3. 医生登录，展示“执业身份已认证”，选择患者、填写病历并添加检查报告，然后发起上链申请。此时只产生链下 AES-GCM 加密草稿，不会产生新区块。
4. 患者进入“上链确认”，核对诊断、说明、附件和 SHA-256 数据指纹，点击“确认内容并同意上链”。
5. 医生进入“上链申请”，在“患者已同意”状态下提交联盟链。后端重新计算摘要，只有与患者确认摘要一致才进入 Raft 共识。
6. 患者打开病历详情，查看患者授权编号与确认摘要，点击“校验”展示附件哈希一致，再展开“查看链上凭证”展示区块哈希和前序哈希。
7. 医生打开当前版本并填写更正原因，生成 V2 草稿；患者再次确认后才能上链。患者端同时展示 V2“当前有效版本”和 V1“已被更正”，原区块仍可追溯。

为了复用现有演示数据，可以直接从第 4 步开始：区块 `#5` 是原始版本，区块 `#6` 是更正版本。

三个节点配置了相同的内部写入密钥，门户会在节点间转发时自动使用。不要把该演示密钥用于公网部署；部署前应通过安全配置管理系统替换三个配置文件中的 `api_key`。
